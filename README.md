# Neural_Network_Project
Project for Summer 2026 - Computer Science class Neural Networks

Idea is to train models on images generated by ChatGPT then see how they handle recognizing real images from different viewpoints. 

Model 01 - Trained on basic images 

Model 02 - Trained on more real-like images from a front view only.

Model 03 - Trained on more real-like images from multiple angles.
